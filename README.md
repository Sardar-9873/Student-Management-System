# 🎓 Student Management System

A modern Student Management System built with React, Vite, Tailwind CSS and Firebase Firestore.


## 🚀 Features

- 🔐 Firebase Authentication
- 📚 Add Students
- ✏️ Update Students
- 🗑️ Delete Students
- 🔍 Search Students
- ⚡ Realtime Firestore Updates
- 📱 Fully Responsive UI


## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- Firebase Firestore
- React Router
- React Icons


## 🌐 Live Demo

(https://student-management-system-five-plum-11.vercel.app/)


## 💻 Installation

```bash
git clone <repository-url>

cd Student-Management-System

npm install

npm run start:dev
```
